# 人工智能 · 领域知识图谱

## 一、知识地图

```
人工智能
├── 机器学习基础
│   ├── 经典方法：线性/逻辑回归、SVM、决策树/集成（GBDT/XGBoost）
│   ├── 统计学习理论：偏差-方差、正则化、VC 维
│   └── 概率图模型：贝叶斯网络、CRF
├── 深度学习
│   ├── 架构演进：MLP → CNN → RNN/LSTM → Transformer → MoE
│   ├── 训练技术：优化器、归一化、正则化、分布式训练
│   └── 表示学习：自编码器、对比学习、自监督预训练
├── 大模型（当前主线）
│   ├── LLM 基础：预训练、指令微调（SFT）、对齐（RLHF/DPO）
│   ├── 能力增强：RAG、工具调用、思维链、长上下文
│   ├── 高效化：量化、剪枝、蒸馏、MoE、KV-cache 优化
│   ├── 智能体（Agent）：规划、记忆、多智能体协作
│   └── 评测：基准污染、人类偏好评测、能力涌现争议
├── 应用领域
│   ├── NLP：理解、生成、机器翻译、信息抽取
│   ├── CV：检测/分割/生成（扩散模型）
│   ├── 多模态：VLM、音视频理解、具身智能
│   └── AI4Science：蛋白质、材料、气象
├── 可信 AI
│   ├── 可解释性：特征归因、机制可解释性
│   ├── 鲁棒性：对抗样本、分布外泛化
│   ├── 公平性与隐私：差分隐私、联邦学习
│   └── 安全与对齐：越狱攻击、幻觉治理、价值对齐
└── 强化学习
    ├── 基础：MDP、Q-learning、策略梯度
    └── 前沿：RLHF、世界模型、具身决策
```

## 二、核心概念速览

| 概念 | 一句话 | 常见研究点 |
|---|---|---|
| Transformer | 自注意力架构，当前一切的基础 | 注意力变体、长序列效率 |
| 预训练-微调范式 | 大规模无监督预训练 + 任务适配 | SFT 数据质量、灾难性遗忘 |
| RLHF | 用人类偏好奖励模型对齐 LLM | DPO 等无 RL 替代方案 |
| RAG | 检索外部知识注入生成 | 检索质量、幻觉抑制、GraphRAG |
| 幻觉 | 生成看似合理但不实的内容 | 检测、归因、缓解（检索/校验） |
| MoE | 稀疏激活的专家混合 | 路由策略、负载均衡、训练稳定性 |
| KV-cache | 推理时缓存注意力键值 | 压缩、分页（vLLM）、长上下文 |
| 智能体 | LLM + 规划 + 工具 + 记忆的自治系统 | 规划可靠性、多智能体协议、评测 |
| 涌现能力 | 规模跨过阈值后出现的新能力 | 是否真实存在（度量争议） |
| 对比学习 | 拉近正样本、推远负样本学表示 | SimCLIP 类方法、负样本构造 |

## 四、常见研究问题（按可行性分层）

### 学生课题高可行区
- RAG 优化：检索-生成的协同、垂直领域适配、幻觉抑制
- Agent 记忆与规划：记忆机制设计、任务分解可靠性
- LLM 评测：特定能力的评测集构建、评测污染检测
- 高效推理：量化/缓存策略在特定硬件上的权衡

### 需要中等资源区
- 小模型蒸馏大模型能力；垂直领域继续预训练；多模态对齐改进

### 大团队重资源区
- 从头预训练、大规模 RLHF、基础模型架构创新 —— 学生队不建议正面进入

## 五、AI 课题特别提示

1. **算力预算是第一约束**：选题前先盘点可用 GPU 资源，倒推能做什么规模的实验
2. **基线更新极快**：2024 年后的实验，基线必须包含当年的强开源模型（Llama/Qwen 系列），用 GPT-3.5 当基线会被直接质疑
3. **评测即贡献**：构建高质量评测集/标注体系，是资源有限时依然能发好工作的路径
4. **警惕基准污染**：训练数据可能包含测试集，结论前必须做污染检查
