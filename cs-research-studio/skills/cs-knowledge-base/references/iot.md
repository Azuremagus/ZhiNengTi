# 物联网（IoT）· 领域知识图谱

## 一、知识地图

```
物联网（三层架构 + 横切关切）
├── 感知层
│   ├── 传感器与执行器：温湿度/惯性/声学/视觉/毫米波雷达
│   ├── RFID 与标识技术
│   ├── 嵌入式系统：MCU（STM32/ESP32）、实时操作系统（FreeRTOS/Zephyr）
│   └── 能量采集与低功耗设计
├── 网络层
│   ├── 短距通信：BLE、Zigbee、Wi-Fi、UWB、NFC
│   ├── 广域低功耗：LoRa/LoRaWAN、NB-IoT、LTE-M、Sigfox
│   ├── 工业网络：Modbus、OPC UA、TSN（时间敏感网络）
│   └── 协议栈上层：MQTT、CoAP、AMQP、HTTP
├── 平台与应用层
│   ├── 边缘计算：边缘网关、边缘推理、云边协同
│   ├── IoT 平台：设备管理、时序数据库（InfluxDB/TDengine）、规则引擎
│   ├── 数字孪生：物理实体的虚拟映射与仿真
│   └── 行业应用：智慧城市、工业互联网、智慧农业、可穿戴/健康
└── 横切关切
    ├── 安全与隐私：轻量级密码、固件安全、入侵检测、联邦学习
    ├── 可靠性：时间同步、容错、OTA 升级
    └── 标准化与互操作性
```

## 二、核心概念速览

| 概念 | 一句话 | 常见研究点 |
|---|---|---|
| MQTT | 发布/订阅式轻量消息协议 | QoS 等级、与 CoAP 的选型对比 |
| CoAP | 受限设备的 RESTful 协议 | 与 HTTP 的映射、可靠传输 |
| LoRaWAN | 长距低功耗广域网协议 | 扩频因子、占空比限制、容量 |
| 边缘计算 | 计算下沉到数据产生处 | 卸载决策、模型分割、云边调度 |
| 时间同步 | 多节点时钟对齐 | RBS/FTSP、微秒级 vs 毫秒级需求 |
| 数字孪生 | 物理系统的实时虚拟副本 | 建模保真度、数据同步时延 |
| 固件安全 | 嵌入式设备软件防护 | 固件逆向、漏洞挖掘（模糊测试） |
| 联邦学习 | 数据不出端的分布式训练 | 通信开销、异构设备、隐私攻击 |
| TSN | 确定性时延的以太网扩展 | 工业控制场景的调度 |

## 四、常见研究问题

- **感知智能**：基于商用设备（Wi-Fi/毫米波/声学）的无接触感知（手势、呼吸、跌倒检测）—— 近年 IMWUT/MobiCom 热门
- **边缘智能**：大模型/深度模型在资源受限设备的部署（量化、剪枝、分割推理）
- **低功耗广域网**：LoRa/NB-IoT 的容量与干扰；无源/反向散射通信（backscatter）
- **IoT 安全**：固件漏洞自动挖掘；僵尸网络（Mirai 类）检测；轻量级认证协议
- **工业物联网**：TSN 调度、预测性维护、数字孪生保真度

## 五、IoT 课题特别提示

1. **实验成本高**：真实硬件实验（多节点、多场景）是加分项但耗时；仿真 + 小规模实测是务实组合
2. **数据集稀缺**：感知类研究常需自采数据，数据集的公开本身是贡献
3. **跨层设计受欢迎**：纯应用层创新容易被质疑深度，"感知层信号处理 + 网络层协议 + 应用层算法"的垂直整合工作更受顶会青睐
